# Daymark marketing site

Editable static source lives in `src/`. Run `node scripts/build.mjs` to copy it to `dist/`, the directory served by Sites.

The site has no runtime dependencies, remote fonts, analytics, cookies, or third-party requests. All screenshots are compressed local copies from the existing Daymark website assets; the original website is left untouched.

The App Store listing and support contact are not published in this preview. Add verified destinations before linking to them.
